Сейчас · Telegram для Codex

Telegram для Codex (Windows), ~20 минут

Зачем: Codex будет читать нужные чаты текстом, а не через скриншоты экрана — дешевле и без ошибок окон. Подключение через открытую программу telegram-mcp (библиотека Telethon). Режим — только чтение: отправлять от твоего имени Codex не сможет.

Правила: ключи (api_id, api_hash) и «строка сессии» — только в файле .env на твоём компьютере. Никому не присылать, ни в чат, ни Дмитрию. Строка сессии = ключ от твоего Telegram. Если утекла: Telegram → Настройки → Устройства → завершить сеанс.

  1. Ключи. Открой my.telegram.org → вход по номеру → API development tools → App title MarinaAssistant, Short name marinaassistant, Platform Desktop → Create. Вкладку не закрывай.
  2. Codex читает код (вставь в Codex): 
    Прочитай код github.com/chigwell/telegram-mcp (README, main.py, session_string_generator.py) и коротко объясни мне, что он делает и есть ли риски. Ничего не ставь.
  3. Если ок — установка (вставь в Codex): 
    1) Проверь git --version и uv --version. Чего нет — спроси у меня «да» на winget install Git.Git / winget install astral-sh.uv. После установки перезапусти Codex.
2) git clone https://github.com/chigwell/telegram-mcp.git C:\AI\tools\telegram-mcp
   Затем в этой папке: uv sync. НЕ используй pip install telegram-mcp и uvx telegram-mcp — под этим именем другой проект.
3) Скопируй .env.example в .env и открой: notepad C:\AI\tools\telegram-mcp\.env
   Я сама впишу TELEGRAM_API_ID и TELEGRAM_API_HASH. Ты добавь строку TELEGRAM_EXPOSED_TOOLS=read-only. Ключи в чат не пиши.
4) Сделай резервную копию и подключи сервер в %USERPROFILE%\.codex\config.toml:
   [mcp_servers.telegram]
   command = "uv"
   args = ["--directory", "C:/AI/tools/telegram-mcp", "run", "main.py"]
   startup_timeout_sec = 60
5) Запомни правило: Telegram только через этот MCP, отправка — только после моего «да».
  4. Строка сессии — сама, в отдельном окне. Win → набери PowerShell → Enter, затем по очереди: 
    cd C:\AI\tools\telegram-mcp
uv run session_string_generator.py --phone
    Введи номер, код из Telegram и пароль (если есть; при вводе не виден — это нормально). На вопрос (y/N) напиши y — строка сама попадёт в .env. Окно закрой.
  5. Перезапуск. Закрой Codex полностью (значок у часов → правой кнопкой → Выход) и открой снова.
  6. Проверка (новый чат Codex): 
    Проверь Telegram MCP: кто авторизован (имя). Прочитай 3 последних сообщения из чата с Дмитрием (@Posbitcoin). Ничего не отправляй. Потом перечисли свои инструменты Telegram.
    Готово, если видно имя и 3 сообщения текстом, а в инструментах нет send / delete / edit.

Застряла на любом шаге — пришли Дмитрию текст ошибки целиком (не только скриншот). Можно сделать вместе на созвоне.

Мост: подключить твой Codex к ИИ Дмитрия

Мост — защищённый канал, где твой Codex и ИИ Дмитрия пишут друг другу без тебя. Тебе приходят только итоги и вопросы «да / нет». Имя твоего агента в мосте — marina-codex, тема — salon-crm.

  1. Сохрани два файла из Telegram (Дмитрий прислал их 17.11): приглашение invite_marina.txt и сертификат server_ca.pem. Положи оба в папку %USERPROFILE%\.murmur\ (вставь этот путь в адресную строку Проводника; нет папки — создай).
  2. Вставь в Codex (лучше в чат «Установи мур мур»): 
    Подключи Мурмур. Имя агента: marina-codex.
Приглашение: %USERPROFILE%\.murmur\invite_marina.txt
Сертификат: %USERPROFILE%\.murmur\server_ca.pem
1) Проверь SHA-256 сертификата, должно быть:
   1e124ae1c989a434fc6e756e7df0a2bd22f95a60e59515586f8870843c2fcf12
   Не совпало — остановись и скажи мне.
2) Сертификат подключай через NODE_EXTRA_CA_CERTS. Проверку TLS не отключай.
3) Выполни murmur join --agent-id marina-codex --invite-file <приглашение> --reply-out %USERPROFILE%\.murmur\reply_marina.txt
4) Покажи мне, где лежит reply_marina.txt. Содержимое приглашения в чат не выводи.
  3. Отправь Дмитрию в Telegram файл reply_marina.txt (это «ответ», он не секретный). ИИ Дмитрия добавит тебя и пришлёт проверку.
  4. Проверка связи (вставь в Codex после ответа Дмитрия): 
    Отправь в Мурмур агенту dmitrii-lead-agent, тема salon-crm:
[PROTO:peer-v0.1] [FROM:marina-codex] [ID:ping-1] [TYPE:msg] ping
Потом через 2 минуты проверь входящие (murmur_inbox, limit 3).
    Готово, если во входящих пришёл pong с тем же ID.

Codex сам не просыпается от новых сообщений моста. Когда нужно — скажи ему «проверь входящие Мурмура». Это нормально.

Вопросы и ответы

Codex пишет, что нет доступа к сети / не может скачать (PyPI, npm, GitHub)
Это песочница Codex, не поломка. Нажми «Разрешить», когда он спросит. Не спрашивает — напиши: «Запроси разрешение на доступ к сети и повтори команду».
Codex предлагает свой способ (например, вход через Telethon вместо telegram-mcp)
Можно, если он показывает код и не просит ключи в чат. Главное правило одно: api_id, api_hash, код входа и строку сессии вводишь только в окне на своём компьютере, в чат — никогда. И пусть режим будет «только чтение», пока сама не решишь иначе.
my.telegram.org: что писать в форме
App title — любое из 5+ латинских букв, например MarinaAssistant; Short name — marinaassistant; Platform — Desktop; URL и Description — пусто. Слово «Telegram» в названии нельзя.
Ошибка про сертификат, TLS, «self-signed», «unable to verify»
Значит, Codex не видит файл server_ca.pem. Скажи: «Подключи сертификат через NODE_EXTRA_CA_CERTS, путь …, и перезапусти». Отключать проверку нельзя.
После установки Codex «не видит» новый инструмент
Закрой Codex полностью (значок у часов → правой кнопкой → Выход) и открой снова. Новые подключения подхватываются только после перезапуска.
Что можно присылать Дмитрию, а что нет
Можно: скриншоты, текст ошибок целиком, файл reply_marina.txt. Нельзя: ключи, пароли, коды, строку сессии, файл приглашения обратно, данные клиентов салона.
Кто мне отвечает в Telegram
Дмитрий и его ИИ (подпись «— ✍️ ИИ»). ИИ отвечает быстро и коротко: «получил, отвечу до …», ссылка на нужный блок, следующий шаг. Всё по существу, деньги и созвоны — сам Дмитрий.
Сломала / сделала не так
Ничего страшного: всё, что мы ставим, откатывается. Пришли текст ошибки целиком — разберём, или сделаем вместе на созвоне.

Правила, которые защищают тебя

  • Ничего не отправляется, не удаляется и не оплачивается без твоего «да».
  • Пароли, ключи и данные клиентов салона в мост не передаются.
  • Перед любым изменением CRM — копия базы.
